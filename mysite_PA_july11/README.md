CondoFix Setup Guide

**Project Overview**

CondoFix is a Python Flask application using SQLite (Central.db) for data storage. The project is configured to work on both your laptop and your uncle's laptop.

Project Structure

After cloning the repository, ensure your project root is correctly set.

1. Set Project Root:

In PyCharm, go to File > Settings > Project: CondoFix > Project Structure.

Ensure the root folder is set to: mysite_PA_july11.
